# Ahri source foundation

Target: standard PC Summoner's Rift 26.18, frozen Riot build 16.18.8175716.
The retained character package is now a reproducible source reference. Ahri is
not registered as a playable champion. This increment generates no runtime
stats, spell controller, bot behavior, saved state, effects or audio.

## Retained inputs

`reference/ahri/character.bin` contains the complete 30,475-byte character BIN.
`character.json` retains its manifest, archive, bundle ranges, file identity and
named records. The original naming response is `names.json`; the independently
versioned public client response is `ddragon-16.18.1.json`. These are exact copies
of the earlier retained research inputs; this increment makes no network request
or repeated archive extraction.

The archive is `DATA/FINAL/Champions/Ahri.wad.client`, from manifest
`29CE6E781C3B6368` (SHA-256
`564984ff169e7554607cae96d3cdca7812dfc5978736e889f347def39142a0cb`).
The raw character SHA-256 is
`121997c9c4ef2ff0f671b659d64d2e22cb71208216ddcc3c4f552a17f196d2cb`.
Manifest, archive and reference version match the existing
[model reference](reference/ahri-model.json).

There are **64 actual records**, plus the `__linked` metadata key containing an
empty array. The decoder compares the entire closure, including every numeric
value, array, field and record. JSON object keys retain their string form.
Named strings can match an unresolved lowercase FNV alias only when the exact
hash agrees. Boolean values cannot pass as numeric zero or one.

## Offline reproduction

The exporter uses Python's standard library:

```sh
python3 tools/assets/export-ahri-declarations.py
python3 tools/assets/export-ahri-declarations.py --check
python3 -O tools/assets/export-ahri-declarations.py --check
```

It writes only `docs/reference/ahri/declarations.json`. Every frozen input is
hash checked before projection. Existing differing output is rejected rather
than overwritten. Check mode writes nothing, including when output is missing.
No source float is rounded and no absent engine field receives a default.

The complete independent decode uses the existing asset-tool environment:

```sh
PYTHONPATH=.tools/cdtb .tools/cdtb-venv/bin/python tools/assets/verify-ahri-character.py
PYTHONPATH=.tools/cdtb .tools/cdtb-venv/bin/python -O tools/assets/verify-ahri-character.py
PYTHONPATH=.tools/cdtb .tools/cdtb-venv/bin/python tools/assets/test-ahri-character.py
PYTHONPATH=.tools/cdtb .tools/cdtb-venv/bin/python -O tools/assets/test-ahri-character.py
```

The decoder is the retained CDTB `binfile.py`, SHA-256
`0c1825135763c98f705535eecf2b4b1a8e667c53181e9e1d43ad7a83d1d844fd`.
It must come from this project's pinned checkout. Explicit runtime guards remain
active under Python optimization. Regression cases reject altered raw bytes,
changed numbers and booleans, missing/extra records, shortened arrays, changed
input files, mismatched public rank tables, absent/ambiguous calculation links
and attempts to overwrite a different output. Both normal and optimized runs
also compare the full positive decode and exact generated bytes.

`tests/ahri-character-source.test.ts` checks the retained identities, all 18 stat
comparisons, independent spell rank arrays, all ten missile declarations,
passive expressions and the distinctions below as part of `npm run check`.

## Observed declarations

Five Q/W/E ranks and three R ranks agree between the client tooltip level counts
and Data Dragon. Cooldowns use slots 1 through N; mana and display range use
slots 0 through N−1. Each public array matches exactly before those slices are
accepted. Named values retain both full arrays and slots 1 through N. This
establishes table alignment, not native rank enforcement.

Seventeen of the 18 base/growth stat comparisons agree within float32 tolerance
after the explicitly recorded regeneration unit conversion. **Attack-damage
growth remains unresolved: the BIN declares 3; Data Dragon declares 0.** Neither
is selected as a runtime policy. Attack-speed ratio, attack offset, selection
shape and navigation radius remain raw character fields. An absent attack-speed
cast-offset scaling field is not assigned another champion's value.

do not establish native charge state; its root has no explicit ammo/charge
field. The mixed-case `rAPCoefficient` link resolves to `RAPCoefficient` by exact
lowercase FNV identity, without rewriting the raw spelling.

## Scope and next work

The independent retained-source audit reparses all records and verifies the 18
earlier research input identities. Its findings are retained at
`.cache/ahri-character-static-review-v1-20261025/findings.json` (SHA-256
`beb0a78a5d4eaeb86fa4062dba72620b54646538eb6ee93b2e7616e1987676ad`).
That audit and this source package establish authored data, not recovered server
callbacks or native gameplay. Descriptive client text cannot resolve the open
damage and state-transition questions by itself.

Next implementation must declare and test local movement, collision, damage,
resource and saved-state policies where positive runtime evidence is absent.
It must retain these source distinctions and expose unresolved choices. The
existing unlit Ahri rig preview also leaves native materials, tail/hair dynamic
modifiers, animation graph, effects and audio unfinished. Complete player/role
integration, strict continuation, production roster and native acceptance remain
open. No shipped simulation or asset is changed by this reference increment.
