# Milestone 7 — Ten-champion match reliability

Milestone 6 certified the ten-champion roster through a 16-minute simulation.
This milestone follows the public 5v5 through a natural Nexus victory, verifies
minute checkpoints and their first second of continued simulation, and exercises
the finished match through the production offline client.

## Save and replay fixes

- At four minutes, both baseline seeds retained a completed four-second Ahri
  Empowered Recall with a planned eight-second audio deadline. Schema 186 saves
  the actual deadline from the accepted channel. It also accepts interruptions
  on the completion tick, when commands or damage resolve before Recall can finish.
- Milestone 6 checkpoints upgrade on load. Both original four-minute saves
  restored to the exact state generated by the corrected build. Replay files
  use their original ruleset to preserve the meaning of their digests.
- The 18-minute save in seed `719` retained a 45-tick Charm on a champion with
  item and rune tenacity. Live control and retained effects now share the same
  duration limits. The corrected build reproduced the saved state from the
  preceding minute and restored it exactly.
- Chrome rounded one retained projectile facing angle differently from Node
  while reproducing every position exactly. The validator now allows a
  `1e-12`-radian tolerance for that recalculated angle and keeps the saved value.
- Replay export captures the tick, state, and command list together before hashing.
  Playback counts each checkpoint once across seeks, verifies the terminal state
  independently, and retains a digest mismatch until the replay is closed.
- The cohort verifier checks the public roster, role assignments and quests in
  every checkpoint. Its per-tick economy check allows levels 19 and 20 after
  the Top quest completes.

The production build uses ruleset
`3627a2c16eda1293133601d28228f0cf913af54fd1f2a72aee0349e78ea39e56`
and the 1,519-file, 581,692,626-byte offline pack
`2428920e85ab78a53a7801d1c8d0068bb3d1869c664cdd4be97d9c4519b4f0d9`.

## Verification

| Seed    | Natural result         | Checked ticks | Exact restores | Continuation checks |
| ------- | ---------------------- | ------------: | -------------: | ------------------: |
| `26018` | Red victory at `26:35` |        95,722 |             27 |                  26 |
| `719`   | Red victory at `27:10` |        97,802 |             28 |                  27 |

Both matches passed the per-tick resource and protected-structure checks. The
53 continuation checks covered 3,180 ticks. Both cohorts ran before the final
projectile angle tolerance was added. The verification compares their frozen
source manifests against the production source and checks that the projectile
validator is the sole changed source file. Each retained checkpoint was then
restored again on the final ruleset in Node and Chrome, with the ruleset field
updated in QA copies. See the [verification ledger](reference/milestone7-verification.json).

The final 2,122 ticks of seed `26018` replayed to the same terminal state with
nine matching SHA-256 checkpoints. Chrome `157.0.8103.38` downloaded the complete
production pack and, with network access disabled, imported the real result,
showed `1/1` hashes in checkpoint replay, and exported identical bytes before
and after reload. The browser recorded 2,297 service-worker responses and zero
page errors, failed requests, or requests outside the deployment prefix.

The production build, asset validation, 108 focused tests, 338 Node QA checks,
and the Chrome ten-champion playtest passed. The broad unit run still has missing
legacy reference inputs and an existing Lux E sampler digest mismatch. The two
seeds and Chrome acceptance define the measured scope of this milestone.

## Reproduction

```sh
npm run build
npm run offline:verify
mkdir -p artifacts
node tools/qa/match-cohort.mjs --jobs 2 --keep-going --snapshot-compression gzip \
  --output .cache/milestone7-verification 26018 719
node tools/qa/verify-match-cohort.mjs .cache/milestone7-verification \
  --output artifacts/milestone7-cohort-verification.json
node tools/qa/offline-completed-match.mjs \
  --report .cache/milestone7-verification/seeds/26018/report.json \
  --output-dir artifacts/milestone7-offline-result
```

The cohort uses Standard difficulty and the existing bot policy for the human
Ashe slot. It keeps the original match clock, economy, and victory rules. The
browser audit uses a disk-backed Chromium profile, downloads the production
pack, then imports, reloads, and exports the terminal checkpoint without network
access. Watching a restored result plays back the saved checkpoint. A replay
recorded during a live session carries the actions from that session.
