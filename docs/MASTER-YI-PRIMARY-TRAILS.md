# Saved primary attack trails

The private Yi fixture renders complete ordinary Attack1, Attack2 and critical
trail systems on accepted primary attacks, using the
[source-declared ordinary choices](MASTER-YI-ATTACK-SELECTION.md). The two passive systems use their
[separate saved Double Strike dispatch](MASTER-YI-PASSIVE-TRAILS.md). No audio is added.

Four verified texture transports retain all 34 authored mip levels. The common
ramp reuses an existing verified asset. All three systems share one page-owned native
weapon-trail geometry with 1,500 corners. Asset failures preserve successful
loads, keep startup usable, and require an explicit retry. Ordinary Ashe/Lux
startup requests no private trail assets or renderer.

The literal source frames 5, 5 and 8 index the retained rendered clip sample arrays.
Default and event aliases must have identical clocks. Admission uses the first
fixed step crossing under the current attack pose rate; particles begin one tick
later. This is an explicit local display policy. Native callback timing and
omitted `mTickDuration` are not calibrated.

Current full position and quaternion come from the named center joint, with no
root fallback for missing or ambiguous joints. Source offsets, critical rotation,
scale, UV scroll and lookup controls are retained. Source-X reflection and 0.01
VFX units remain local choices. Attack1 and Crit omit blend; Attack2 explicitly authors blend 4. All omit local
frame flags. The local blend-zero omission policy and bound joint adapter do not turn those
omissions into authored controls. Rig scale inheritance, native placement and
shader parity remain uncalibrated.

Schema 162 retains a rolling lossless 20-tick actor-root/visibility window to each
accepted primary attack record. The small simulation marker table keeps texture
and geometry metadata outside the simulation import graph. Decoding checks exact
coverage, canonical runs, current endpoints and audience. Root collection and
cosmetic sampling consume no gameplay randomness or entity IDs.

Cancellation or death before the marker suppresses admission. Already admitted
finite particles survive cancellation and follow current known corpse poses.
Hidden births never appear after reveal; Q hides the current bound effect.
Victory drains admitted tails through presentation time without stepping the
world or admitting future attack markers. Save/Load preserves the same particles
and exact future world state.
